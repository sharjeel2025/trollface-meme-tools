## 😂 What Is This?

This repository houses a set of fun, client‑side utilities for creating and customising memes – from the iconic **Troll Face** to rage comics, scary text effects, and emoji generators. Everything runs in your browser, so you can start making memes instantly without installing anything.

Whether you're a content creator, a meme enthusiast, or just want to prank your friends, these tools give you the power to generate hilarious content in a few clicks.

## 🛠️ Tech Stack

- **HTML5, CSS3, Vanilla JavaScript** – Core frontend technologies.
- **Canvas API** – For rendering text and images in real time.
- **CSS Grid & Flexbox** – Responsive layouts that look great on any device.

No frameworks, no external dependencies – just clean, lightweight code.

## 🚀 Quick Start

### Use the live tools
Visit **[trollfacedownload.com](https://trollfacedownload.com)** and start creating memes immediately.

### Run locally
```bash
git clone https://github.com/sharjeel2025/trollface-meme-tools.git
cd trollface-meme-tools
open index.html
```

Each tool is a standalone HTML file – just double‑click to open.
